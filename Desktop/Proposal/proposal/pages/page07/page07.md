**Intern Dashboard**

### Introduction

LeadFlow guides interns through their daily calling schedule. The interface prioritizes active assignments, displays real-time targets, and provides direct communication triggers for instant lead engagement.

By consolidating tasks onto a single screen, interns focus entirely on outreach instead of administrative data entry.
