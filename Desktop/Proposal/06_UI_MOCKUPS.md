# Purpose

This document serves as the UI Design Guide for the LeadFlow proposal. It outlines the visual layouts, layout objectives, and primary interface elements for the seven core screens presented to the client.

These mockups demonstrate how recruitment workflows are centralized, simplified, and visual-first, adhering to the design standards of premium modern SaaS products.

---

# General Layout Standards

- **Desktop Layout:** Standard left-sidebar navigation layout. The sidebar lists core operations, while the header contains search, user profile, and notification triggers. The main content workspace uses rounded cards, clean spacing, and clear headers.
- **Mobile Layout:** Compact mobile layout optimized for Progressive Web App (PWA) operation. Features top header, single-column scrollable lead details, and bottom navigation bar.

# Core UI Mockups (7 Screens)

## Mockup 01: Login Screen (Page 05)

### Business Objective
Introduce a secure and professional landing interface that reinforces brand trust and security.

### Layout
Center-aligned login card on a minimal light/dark background.

### Primary Components
- LeadFlow brand logo and title.
- Clear email and password entry inputs.
- Single distinct primary button (Sign In).
- Link to request registration access.

### Visual Hierarchy
1. Brand Logo & Product Title (Dominant)
2. Card Container (Focus Area)
3. Credentials Fields (Inputs)
4. Primary Action Button (Call to Action)

---

## Mockup 02: Manager Dashboard (Page 06)

### Business Objective
Provide managers with immediate visibility into daily recruitment operations, team activity, and overall performance.

### Layout
Desktop left-sidebar navigation layout. The main workspace displays high-level metric cards followed by analytics charts and leaderboard rankings.

### Primary Components
- Left navigation sidebar.
- KPI metric cards (Total Leads, Assigned, Call Progress, Completed).
- Activity summary charts (weekly call volumes and source conversion rings).
- Active team member summary list showing recruiter statuses.

### Visual Hierarchy
1. High-Level KPI Metric Cards (Dominant)
2. Operational Summary Charts (Primary Visual)
3. Recruiter Leaderboard List (Secondary Details)
4. Navigation Sidebar (Structural context)

---

## Mockup 03: Intern Dashboard (Page 07 - Recruiter Workspace)

### Business Objective
Empower recruiters to manage their assigned candidates, contact leads, and update records from a single page.

### Layout
Desktop layout containing a focused task dashboard. Features key daily actions and a prominent lead table.

### Primary Components
- Daily target checklist (Leads called, calls remaining, follow-ups due).
- Interactive Lead Table.
- One-click call and wa.me redirect buttons for each lead row.
- Search and filtering panel.

### Visual Hierarchy
1. Active Leads Table (Dominant)
2. Daily Progress Target Cards (Supporting Metrics)
3. Direct Communication Action Buttons (Call / WhatsApp)
4. Filter Controls (Utility)

---

## Mockup 04: Mobile PWA Dashboard (Page 10)

### Business Objective
Ensure recruitment teams can work on the go with a mobile-first, responsive workflow dashboard.

### Layout
Compact, single-column vertical layout optimized for touch targets (minimum 44pt / px) and thumb navigation.

### Primary Components
- Header with greeting and network sync status.
- Horizontal scroll card array for priority actions.
- Stacked candidate detail cards.
- Bottom mobile navigation bar (Dashboard, Leads, Reports).

### Visual Hierarchy
1. Core Action Cards (Primary Actions)
2. Candidate Lead Details List (Main Content)
3. Bottom Navigation Icons (Control)

---

## Mockup 05: Lead Management Table (Page 08)

### Business Objective
Give managers a comprehensive database view to import, filter, allocate, and monitor leads.

### Layout
Full-width desktop table layout with utility search bars and bulk action buttons.

### Primary Components
- Data management controls (Import CSV, Assign Selected, Export).
- Table headers with sorting indicators.
- Lead status badges (Interested, Call Back, Completed, No Response).
- Assignee column mapping leads to specific interns.

### Visual Hierarchy
1. Action Toolbar (Import / Assign / Export Controls)
2. Unified Lead Database Table (Grid View)
3. Color-Coded Status Badges (Visual Indicators)

---

## Mockup 06: Analytics Dashboard (Page 09)

### Business Objective
Provide decision-makers with a visual breakdown of recruitment conversion funnels and productivity patterns.

### Layout
Multi-panel desktop layout containing clean data visualizations and minimal reports.

### Primary Components
- Funnel chart showing lead progression (Imported → Called → Interested → Completed).
- Bar charts tracking call durations and intern call volumes.
- Leaderboard panel ranking team performance.
- Date range selectors.

### Visual Hierarchy
1. Core Funnel Chart (Dominant)
2. Recruiter Productivity Rankings (Secondary Data)
3. Performance Filter Selectors (Utility)

---

## Mockup 07: Daily Report (Page 09)

### Business Objective
Generate daily summary summaries that managers can copy, print, or share to keep teams aligned.

### Layout
Clean document layout displaying a structured list of metrics, suitable for PDF download or text sharing.

### Primary Components
- Document header displaying date and batch metadata.
- Performance statistics blocks.
- List summarizing status counts (Leads called, interested, pending, rejected).
- Copy text and download PDF action buttons.

### Visual Hierarchy
1. Document Header & Title (Context)
2. Performance Stats Cards (Metrics)
3. Share & Export Action Buttons (Call to Action)
