## 05_VISUAL_REQUIREMENTS.md

---

# Purpose

This document defines every visual element required throughout the LeadFlow Software Proposal.

The proposal should communicate visually before it communicates through text.

Every visual must have a purpose.

Every illustration, mockup, diagram, icon, card, and layout should support the story being told.

Avoid decorative graphics that do not add business value.

---

# Visual Philosophy

The proposal should resemble premium SaaS presentations produced by:

- Stripe
- Linear
- Notion
- HubSpot
- Vercel
- Rippling
- Figma

The visual language should be:

- Minimal
- Premium
- Modern
- Enterprise-focused
- Clean
- Consistent

The proposal should never resemble a software manual or technical report.

---

# General Visual Rules

Every page should contain:

✓ One dominant visual

✓ One supporting visual (optional)

✓ Supporting icons

✓ Plenty of whitespace

Avoid using multiple competing visuals on one page.

One page should communicate one primary idea.

---

# Illustration Style

Preferred

- Workflow illustrations
- Dashboard wireframes
- Process diagrams
- Data visualization
- Connected node graphics
- Product illustrations
- Minimal abstract graphics

Avoid

- Cartoon illustrations
- People shaking hands
- Office stock photography
- Generic business photos
- 3D artwork
- Heavy gradients

---

# Dashboard Mockups

Dashboard mockups should look realistic.

They should feel like an actual product.

Every dashboard should follow the LeadFlow design system.

Requirements

- White cards
- Soft shadows
- Rounded corners
- Clean spacing
- Large KPIs
- Minimal borders
- Consistent typography
- Professional charts

Use realistic interface labels.

Avoid placeholder text like:

Lorem Ipsum

Sample

Demo

Placeholder

# Charts

Use only

- KPI Cards
- Line Charts
- Bar Charts
- Donut Charts
- Progress Rings
- Leaderboards

Avoid

- 3D charts
- Decorative graphics
- Complex visualizations

Charts should reinforce business insights.

---

# Tables

Tables should appear only when necessary.

Rules

- Rounded container
- Sticky header (inside UI mockups)
- Alternating rows
- Minimal borders
- Plenty of spacing

---

# Image Style

If external imagery is required,

Use

- Dashboard renders
- UI illustrations
- Product-focused visuals

Never use

- Stock office photos
- Smiling teams
- Business handshakes
- Generic corporate imagery

LeadFlow is the hero, not the people.

---

# Visual Consistency Checklist

Before approving any page, verify

✓ One dominant visual

✓ Visual supports the page objective

✓ Correct icon style

✓ Consistent spacing

✓ Correct color palette

✓ Rounded cards

✓ Minimal layout

✓ Professional SaaS appearance

✓ No unnecessary decoration

✓ Editable assets whenever possible

---

# Export Requirements

Every visual should be exportable as:

- SVG (preferred)
- PNG (high resolution)
- PDF (if required)

Editable source files should always be retained for future modifications.

---

# Final Principle

Every visual should answer one question:

**"Does this make the proposal easier to understand?"**

If a visual exists only for decoration, remove it.

The proposal should achieve clarity through purposeful design rather than visual complexity.
