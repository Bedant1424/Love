# Purpose

This document defines every visual element required throughout the LeadFlow Software Proposal.

The proposal should communicate visually before it communicates through text.

Every visual must have a purpose.

Every illustration, mockup, diagram, icon, card, and layout should support the story being told.

Avoid decorative graphics that do not add business value.

---

# Visual Philosophy

The proposal should resemble premium SaaS presentations produced by:

- Stripe
- Linear
- Notion
- HubSpot
- Vercel
- Rippling
- Figma

The visual language should be:

- Minimal
- Premium
- Modern
- Enterprise-focused
- Clean
- Consistent

The proposal should never resemble a software manual or technical report.

---

# General Visual Rules

Every page should contain:

✓ One dominant visual

✓ One supporting visual (optional)

✓ Supporting icons

✓ Plenty of whitespace

Avoid using multiple competing visuals on one page.

One page should communicate one primary idea.

---

# Illustration Style

Preferred

- Workflow illustrations
- Dashboard wireframes
- Process diagrams
- Data visualization

- Product illustrations
- Minimal abstract graphics

# Charts

Use only:
- KPI Cards
- Line Charts
- Bar Charts
- Donut Charts
- Progress Rings
- Leaderboards

Charts should reinforce business insights and avoid decorative colors.

---

# Tables

Tables should appear only when necessary.

Rules:
- Rounded containers (`rx=8`)
- Alternating row colors
- Minimal borders
- Generous text padding

---

# Image Style

If external imagery is required,

Use
- Dashboard renders
- UI illustrations
- Product-focused visuals

Never use
- Stock office photos
- Smiling teams
- Business handshakes
- Generic corporate imagery

LeadFlow is the hero, not the people.

---

# Visual Consistency Checklist

Before approving any page SVG, verify:
✓ One dominant visual is used
✓ Margins follow L=42, R=553, width=511 layout
✓ Spacing adheres to the 8-point system
✓ Colors use Slate neutrals and LeadFlow Blue (#2563EB)
✓ Border radii follow 12pt (primary panels) and 8pt (secondary elements)
✓ Takeaway card aligns to y=722 (Pages 2-11) or y=640 (Pages 12-17)

---

# Export Requirements

Every visual should be maintained as:
- SVG (production code)
- PNG (reference preview)
- PDF (print output)

---

# Final Principle

Every visual should answer one question:

**"Does this make the proposal easier to understand?"**

If a visual exists only for decoration, it must be removed.

The proposal should achieve clarity through purposeful design.
