# Purpose

This document defines the visual design system for the LeadFlow proposal.

The goal is to create a proposal that feels comparable to presentations produced by premium SaaS companies such as Stripe, Linear, Notion, HubSpot, Rippling, Vercel, and Figma.

Every page should feel intentional, modern, and executive-friendly.

This document serves as the single source of truth for layout, spacing, typography, hierarchy, visual consistency, and presentation design.

---

# Design Philosophy

The proposal should communicate confidence through simplicity.

Every page should:

- Feel spacious
- Prioritize readability
- Minimize unnecessary text
- Guide the reader naturally
- Maintain visual consistency
- Balance content with whitespace

Avoid making the proposal feel like a software specification or academic report.

Instead, design it like a premium SaaS product presentation.

---

# Overall Layout

Every page should follow the same hierarchy.

```
Hero

↓

Introduction

↓

Primary Content

↓

Visual / Diagram / Mockup

↓

Key Takeaway
```

Readers should understand the page in under 15 seconds.

# Page Structure

Every page should contain the following sections whenever applicable.

## Hero

Large page title.

One sentence subtitle.

Maximum:

2 lines.

---

## Primary Section

Main explanation.

Prefer cards over paragraphs.

---

## Visual Section

One dominant visual.

Examples:

- Dashboard Mockup
- Workflow
- Diagram
- Timeline
- Architecture
- Analytics
- Feature Cards

Never use multiple competing visuals.

---

## Bottom Section

A highlighted takeaway.

Purpose:

Reinforce the main message of the page.

Usually displayed inside a callout card.

# Mockups

Every dashboard mockup should follow the LeadFlow brand.

Rules:

Rounded cards

Minimal charts

Consistent spacing

Large KPIs

Soft shadows

Professional tables

No fake lorem ipsum paragraphs

Use realistic labels.

---

# Diagrams

Every workflow should follow:

Rounded boxes

↓

Blue arrows

↓

Minimal labels

Avoid decorative graphics.

---

# Tables

Tables should contain:

Sticky Header (when represented in UI mockups)

Compact rows

Rounded container

Alternating row colors

Subtle borders

No vertical grid lines unless required.

---

# Charts

Only use:

Bar Chart

Line Chart

Donut Chart

Progress Ring

KPI Cards

Leaderboards

Avoid:

3D charts

Pie charts with many categories

Decorative charts

---

# Photography

Do not use stock office photos.

Do not use smiling business people.

Instead use:

Dashboard mockups

Illustrations

Workflow diagrams

Minimal graphics

# Animation Inspiration

Although the proposal is static, it should look like it belongs to a product that would use:

Slide

Scale

Subtle transitions

# Consistency Rules

Every page must feel like it belongs to the same presentation.

Maintain:

Typography

Spacing

Margins

Icon style

Card design

Color palette

Diagram style

Illustration style

Writing tone

Do not introduce new visual styles after Page 1.

---

Before finalizing any page, verify:

✓ Clear page objective

✓ One dominant visual

✓ No paragraph longer than 3 lines

✓ Consistent spacing

✓ Proper hierarchy

✓ Enough whitespace

✓ Brand colors respected

✓ Lucide icons only

✓ No clutter

✓ Executive-friendly appearance

✓ Easy to understand within 15 seconds

# Design Goal

The finished proposal should look like it was produced by a premium SaaS product company rather than a freelance software document.

If printed or presented digitally, every page should feel polished, modern, and consistent with the LeadFlow brand identity.
