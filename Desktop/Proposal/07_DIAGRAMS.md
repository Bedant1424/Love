# LeadFlow Proposal
## 07_DIAGRAMS.md

---

# Purpose

This document defines every diagram required throughout the LeadFlow Software Proposal.

The proposal should explain ideas visually wherever possible.

Diagrams should simplify complex concepts rather than decorate the proposal.

Every diagram should be:

- Minimal
- Professional
- Easily understandable
- Consistent
- Fully editable (SVG preferred)

These diagrams should be recreated in Canva or Figma using the LeadFlow Design System.

---

# Diagram Style

All diagrams should follow the same visual language.

Boxes

- White background
- 16px corner radius
- Thin gray border
- Soft shadow

Connectors

- Straight or slightly curved
- Blue (#2563EB)
- 2px thickness
- Arrowheads

Typography

- Poppins for titles
- Inter for labels

Spacing

Generous whitespace.

Never overlap elements.

# Consistency Checklist

Before approving any diagram verify:

✓ One clear purpose

✓ Minimal layout

✓ Same arrow style

✓ Same box radius

✓ Same typography

✓ Same spacing

✓ Same color palette

✓ Same icon style

✓ Easily understandable in under 10 seconds

---

# Final Principle

Every diagram should reduce the amount of text needed on the page.

If a concept can be explained visually, prefer a diagram over a paragraph.

Every diagram should make the proposal easier to understand and strengthen the overall presentation.
